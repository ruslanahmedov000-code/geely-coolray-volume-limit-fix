# Решение проблемы Geely Coolray: ограничение громкости

Magisk-модуль, который делает звук штатной магнитолы Geely Coolray громче. Он автоматически включает при каждом запуске магнитолы усиление громкости (эффект **Loudness Enhancer**), так что отдельное приложение-усилитель запускать перед поездкой больше не нужно.

> ⚠️ **Нужны root-права и Magisk.** Без root модуль не установится и не будет работать.

## На чём проверялось

| | |
|---|---|
| Машина | **Geely Coolray 1.5, 2024 г. в.**, привезён по **параллельному импорту** |
| Магнитола | ECARX IHU535G |
| Прошивка | Android 9, Community-прошивка с root |
| Magisk | 30.7 |

Проверка шла на одной машине. На других комплектациях, магнитолах и прошивках работа не гарантирована.

## В чём проблема

- Регулятор громкости магнитолы (0–39) на максимуме даёт **0 дБ**. Это полный цифровой сигнал, громче Android сделать не может, поэтому многим водителям звука не хватает.
- Приложения-усилители вроде «Усилитель громкости» помогают: они накладывают на весь звук штатный эффект Loudness Enhancer. Но их нужно **включать вручную при каждом запуске машины**, и усиление пропадает, если приложение выгрузить из памяти.

## Что делает модуль

- Примерно через 20 секунд после запуска магнитолы включает Loudness Enhancer на весь звук: музыку, радио, CarPlay, навигацию.
- Каждые 5 секунд проверяет, что усиление на месте, и восстанавливает его, если оно пропало.
- Усиление настраивается от **0 до 15 дБ**, по умолчанию **+8 дБ**. Новое значение применяется через 5 секунд, без перезагрузки.
- Регулятор громкости в машине работает как обычно, усиление добавляется поверх него.
- Системные файлы не изменяет. Работает отдельный процесс, который запускается при загрузке через Magisk.

## Установка

1. Скачайте [`RamAuto-VolumeBoost-magisk.zip`](RamAuto-VolumeBoost-magisk.zip).
2. Скопируйте его на магнитолу, например с флешки.
3. Откройте **Magisk → Модули → Установить из хранилища** и выберите zip.
4. Перезагрузите магнитолу.
5. **Отключите или удалите** другие приложения-усилители громкости. Если работают сразу два усилителя, они перехватывают эффект друг у друга.
6. Примерно через минуту после загрузки включите музыку.

## Настройка уровня усиления

**На магнитоле** (нужен эмулятор терминала):

```
su -c ramauto-volume        # показать текущий уровень и последние записи журнала
su -c ramauto-volume 10     # установить +10 дБ
su -c ramauto-volume 0      # выключить усиление
```

**С компьютера на Windows через ADB:** запустите [`windows/RamAuto-Volume.bat`](windows/). Скрипт подключится к магнитоле, покажет текущий уровень и спросит новый. Нужен установленный Android platform-tools (ADB) и включённая отладка на магнитоле.

**Рекомендация:** начните с 8 дБ и подбирайте на слух. Выше 10–12 дБ встроенный ограничитель начинает «сжимать» музыку, а на максимальной громкости можно перегрузить динамики.

## Как проверить, что работает

- Включите музыку на средней громкости, например 20 из 39.
- Выполните `su -c ramauto-volume 0`, подождите 5 секунд, затем `su -c ramauto-volume 12`. Разница должна быть хорошо слышна.
- Журнал работы модуля: `/data/adb/ramauto_volume/keeper.log`. Если всё в порядке, в нём есть строка `boost on: +N dB`.

## Удаление

Magisk → Модули → RamAuto Volume Boost → Удалить → перезагрузка. Звук вернётся к заводскому.

## Состав репозитория

| Путь | Что это |
|---|---|
| `RamAuto-VolumeBoost-magisk.zip` | Готовый модуль для установки через Magisk |
| `module-source/` | Исходники модуля: скрипты Magisk, команда `ramauto-volume` и исходный код `VolumeKeeper.java` |
| `windows/` | Скрипт для Windows: смена уровня и сбор состояния модуля через ADB |

### Как устроен модуль

- `service.sh` запускается Magisk после загрузки системы. Он стартует небольшой Java-процесс (`keeper.dex`) через `app_process` с правами root.
- Этот процесс создаёт `LoudnessEnhancer` на общей сессии звука (session 0, это весь звук магнитолы) с уровнем из файла `/data/adb/ramauto_volume/gain_db`.
- Если процесс завершится, `service.sh` перезапустит его.
- `keeper.dex` собран из `module-source/VolumeKeeper.java`.

## Отказ от ответственности

Вы устанавливаете модуль на свой страх и риск. Изменение громкости сверх заводской может перегрузить динамики. Модуль не собирает и не передаёт никаких данных.
